## Source reconstruction and ID lock

The structured source modules were mechanically reconstructed from the Phase 0 extract
`tests/fixtures/extracts/TakhreejAsaneedAQU.data.json` (SHA-256
`3e4f61186fa0df8dbc3c91951f997afb397efb174636c78e678f3e8090ba1f96`). The fixture is the
verified rendered payload, not the original manuscript. Source options are represented as a
correct answer plus wrong-answer slots; the original source-slot order is unavailable, so the
ID bootstrap records today's displayed option order directly from the baseline page. The lock
marks this with `option_order: "captured-from-baseline"`.

The ID lock was generated by the repository CLI from the baseline commit. It preserves all 163
card IDs, all 249 question IDs and displayed option orders, 29 topics and 7 maps. The chapter
anchor uses the printed-page boundary at page 134; the rule maps every quiz entry to its
existing chapter label. No IDs were changed, retired or reused.

Two lesson blocks have no printed-page reference in the live content. They remain listed as
unreviewed exceptions in `books/takhreej-asaneed/page-references.json`; no page references were
inferred or added.
